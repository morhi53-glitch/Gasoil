# Gasoil PWA lista para GitHub Pages

## Archivos
- index.html  (app completa)
- manifest.webmanifest
- sw.js

## Uso en GitHub Pages
1. Crea un repo en GitHub y sube estos tres archivos (y este README si quieres).
2. Ve a Settings → Pages y selecciona:
   - Source: Deploy from a branch
   - Branch: main, carpeta raíz (/)
3. Guarda. GitHub generará una URL del tipo:
   https://TU_USUARIO.github.io/NOMBRE_REPO/

4. En el iPhone:
   - Abre esa URL en Safari.
   - Pulsar Compartir → "Añadir a pantalla de inicio".

La app se instalará como PWA y guardará los datos en el dispositivo.
